# 閉校・廃校研究の引用マップ

日本の廃校・学校統廃合研究について、最先端の論文4本が実際に何を引用しているかを参考文献リストから復元した引用系譜図です。

**[index.html](index.html)** が本体（1ファイル完結・外部依存なし）。ブラウザで開いてください。GitHub上で読むならファイルをダウンロードするか、raw を [htmlpreview](https://htmlpreview.github.io/) に通すと表示できます。

## 何が見えるか（31ノード・6系統）

- **6つの系統** — 教育社会学／財政・経済／建築計画・都市計画／海外・農村人口減少／コミュニティ・社会教育／記憶・喪失。同じ「学校が閉じる」現象を扱いながら、起点も引用先も重ならない
- **共通祖先2つ** — 斎尾直子2008（茨城県30年の悉皆調査）と野澤・恒川シリーズ（東海4県423校）。複数の最先端が揃って引く結節点
- **分野の分断** — 建築計画系は教育社会学の古典（若林・葉養）を引いていない
- **橋の不在** — 建築計画・都市計画の系統から、コミュニティ・記憶の2系統へ入る矢印は1本もない。閉校の記憶や語りを扱う研究は social science 側に存在するが、跡地活用を論じる側がそれを読んでいない

## 元データ

各論文のPDF本文・J-STAGEから実際に取得した参考文献リストに基づきます（坂本2024=全16件、鈴木2024=全19件、小野西野2024=全30件、新藤2013/2014=全45件/全13件、水野2026=全31件、青木2016=脚注引用のみ）。推測による引用関係の線は引いていません。

書誌情報は引用前に原典で確認してください。2024年刊行分の被引用数0は、刊行が新しく蓄積が始まっていないことを意味します。
